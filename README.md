# Gerenciador de Tarefas em Python

Sistema simples de gerenciamento de tarefas desenvolvido em Python utilizando listas, dicionários, funções e estruturas de repetição.

## Funcionalidades

- Adicionar tarefas
- Listar tarefas
- Marcar tarefas como concluídas
- Remover tarefas
- Menu interativo no terminal

## Tecnologias Utilizadas

- Python 3

## Conceitos Praticados

- Funções
- Listas
- Dicionários
- Estruturas condicionais (if/elif/else)
- Estruturas de repetição (while e for)
- Manipulação de entrada do usuário (input)
- Modularização de código

```text
gerenciador-de-tarefas-python/
```

## Como Executar

```bash
python main.py
```

## Exemplo de Uso

```text
Menu de tarefas

1 - Adicionar Tarefa
2 - Listar tarefas
3 - Marcar como concluída
4 - Remover tarefa
5 - Sair
```
